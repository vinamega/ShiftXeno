# ShiftXeno

ShiftXeno is a distributed, real-time data processing engine utilizing machine-learning algorithms to dynamically manage scalable server clusters.

ShiftXeno is aimed at developers who need a straightforward, dependable solution.

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/ShiftXeno.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
